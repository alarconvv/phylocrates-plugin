# Reasoning-source map

| PhyloCrates function | Primary source role |
|---|---|
| Elicit motivating problem | Harmon: macroevolutionary framing |
| Challenge single favored explanation | Sober: explanatory alternatives/adaptationism |
| Add non-adaptive alternative | Sober, especially adaptationism debates |
| Distinguish inherited similarity from repeated evidence | Funk & Brooks; Felsenstein conceptual comparative logic |
| Refine evolutionary predictions | Harmon: process-to-pattern framing |
| Guard against model → mechanism leap | Harmon/Felsenstein/Yang conceptual statistical framing |
| Treat ancestral claims as conditional | Felsenstein/Yang/Revell & Harmon background |
| Preserve multiple live explanations | Sober: open competing explanations |

This map is conceptual. It is not a method-selection map.
